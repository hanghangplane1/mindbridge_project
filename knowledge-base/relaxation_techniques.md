# 心理放松技巧

## 呼吸调节法

### 4-7-8 呼吸法
1. 完全呼气，嘴唇微张
2. 闭嘴，用鼻子吸气，心中默数4秒
3. 屏住呼吸，默数7秒
4. 用嘴巴完全呼气，发出"呼"声，默数8秒
5. 重复3-5次

适合：入睡困难、焦虑发作、紧张时刻

### 腹式呼吸
1. 坐或躺，一只手放在胸口，一只手放在腹部
2. 用鼻子慢慢吸气，感受腹部鼓起（胸口尽量不动）
3. 用嘴巴慢慢呼气，感受腹部回落
4. 每次吸气4秒，呼气6秒，重复5-10次

适合：考试前紧张、公众演讲焦虑、日常放松

### 方块呼吸（4x4呼吸）
1. 吸气4秒
2. 屏住4秒
3. 呼气4秒
4. 屏住4秒
5. 重复

适合：注意力不集中、需要快速平静时

## 正念冥想

### 正念呼吸
1. 找一个安静的地方，坐直或躺下
2. 闭上眼睛，注意力放在呼吸上
3. 感受空气进入和离开身体的感觉
4. 当思绪飘走时（这很正常），温和地把注意力带回呼吸
5. 从5分钟开始，逐渐延长到15-20分钟

### 身体扫描
1. 躺下，闭上眼睛
2. 从脚趾开始，注意脚趾的感觉（温度、触感、有没有紧张）
3. 慢慢向上移动注意力：脚掌→脚踝→小腿→膝盖→大腿→腹部→胸部→手指→手臂→肩膀→颈部→面部→头顶
4. 在每个部位停留10-15秒，观察感觉
5. 全程10-20分钟

适合：入睡困难、身体紧张、压力大时

### 正念行走
1. 找一个安静的空间，缓慢行走
2. 注意脚底接触地面的感觉
3. 注意每一步的抬起、移动、落下
4. 配合呼吸：吸气时抬脚，呼气时落脚
5. 走10-15步后转身，继续

适合：无法静坐时、需要转换心情时

## 渐进式肌肉放松法

1. 找一个安静的地方，坐或躺
2. 按照以下顺序，每组肌肉紧张5秒，然后放松10-15秒
3. 顺序：双手握拳→前臂→上臂→耸肩→皱眉→张嘴→颈部→胸部→腹部→臀部→大腿→小腿→脚趾
4. 紧张时感受肌肉收缩，放松时感受肌肉松弛的感觉
5. 全程15-20分钟

适合：身体紧张、头痛、失眠、考试前焦虑

## 情绪调节技巧

### STOP 技术
- S（Stop）：停下手中的事情
- T（Take a breath）：深呼吸一次
- O（Observe）：观察自己的情绪和想法（不评判）
- P（Proceed）：有意识地选择下一步行动

### 情绪日记法
每天花5分钟记录：
1. 今天发生了什么？（客观描述）
2. 我有什么感受？（具体情绪词）
3. 身体有什么感觉？（哪里紧张、哪里不舒服）
4. 我有什么想法？（脑海里浮现的念头）
5. 我是怎么应对的？（做了什么事情）

### 5-4-3-2-1 感官接地法
当感到极度焦虑或恐慌时：
- 看：说出你看到的5样东西
- 听：说出你听到的4种声音
- 触：感受到的3种触觉
- 闻：闻到的2种气味
- 尝：尝到的1种味道

适合：惊恐发作、极度焦虑、闪回体验

## 认知重构

1. 识别自动思维："我一定考不好""他们肯定在笑话我"
2. 寻找证据：支持这个想法的证据是什么？反对的证据是什么？
3. 替换为平衡思维："我上次复习不够所以没考好，这次准备充分了，应该会比上次好"

## 日常放松建议

- 每天安排15-30分钟的"自我时间"
- 培养一个不需要竞争的爱好的（听音乐、画画、种花）
- 保持每周3次有氧运动（跑步、游泳、打球）
- 减少睡前电子设备使用
- 与信任的朋友定期交流
