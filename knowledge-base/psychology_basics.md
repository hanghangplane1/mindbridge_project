# 校园心理健康基础知识

## 什么是心理健康

心理健康是指个体在认知、情感和行为上保持良好状态，能够适应环境、发挥潜能、有效应对压力，并为他人和社会做出贡献。心理健康不仅仅是"没有心理疾病"，更是一种积极的心理状态。

## 常见心理困扰及表现

### 1. 学业压力
- 考试焦虑：考前失眠、注意力不集中、手心出汗、心慌
- 拖延行为：明知该做却无法行动，伴随自责和焦虑
- 完美主义：对自己要求过高，害怕失败，难以接受不完美

### 2. 人际关系困扰
- 宿舍矛盾：生活习惯差异、边界感不清、沟通不畅
- 社交焦虑：在公共场合感到紧张、害怕被评价、回避社交
- 亲密关系：恋爱困扰、失恋痛苦、依赖与独立的平衡

### 3. 情绪问题
- 持续低落：超过两周的情绪低落、兴趣减退、精力下降
- 过度焦虑：难以控制的担忧、肌肉紧张、坐立不安
- 愤怒管理：情绪爆发后的内疚、难以控制脾气

### 4. 自我认同困惑
- 大学生处于自我同一性探索阶段，常出现"我是谁""我未来要做什么"的困惑
- 比较心理：与他人比较产生的自我怀疑
- 价值迷茫：找不到意义感、目标缺失

## 心理调适的基本原则

1. **接纳情绪**：所有情绪都有其功能，不需要否定或压抑负面情绪
2. **适度表达**：通过合适的渠道表达情绪，而不是完全压抑或失控发泄
3. **寻求支持**：人际关系是心理健康的重要保护因素
4. **保持规律**：规律作息、适度运动、均衡饮食是心理健康的基础
5. **设立边界**：学会说"不"，保护自己的时间和精力

## 常见的认知偏差

- 非黑即白：把事情看成绝对的好或坏
- 过度概括：因为一次失败就认为自己永远不行
- 灾难化：把问题想象成最坏的结果
- 个人化：把不相干的事情归咎于自己

## 心理健康与心理疾病的区别

心理健康问题不等于心理疾病。偶尔的情绪低落、焦虑是正常反应。如果症状持续超过两周、严重影响日常生活、或出现伤害自己/他人的念头，则需要寻求专业帮助。
